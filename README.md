## 🎯 چرا یادگیری خط فرمان (CLI) حیاتی است؟

در دنیای مدرن نرم‌افزار، ابزارهای اصلی توسعه مانند Node.js، npm/pnpm، Git، پایگاه‌های داده، ابزارهای ابری و SSH **همگی مبتنی بر خط فرمان هستند.** تکیه بر رابط‌های گرافیکی محدودیت‌های زیادی ایجاد می‌کند، در حالی که خط فرمان سرعت، دقت و امکان اتوماسیون بی‌نظیری را فراهم می‌سازد. خبر خوب: یادگیری CLI بسیار لذت‌بخش و منطقی است، زیرا نتایج آن فوری و در کار روزمره کاملاً ملموس است.

پس از اتمام این دوره:
- هر پروژه یا مخزنی را به سرعت دریافت و با پکیج منیجرها اجرا می‌کنید.
- خطاهای مسدود شدن پورت‌ها یا کرش پروسه‌ها را در چند ثانیه شناسایی و برطرف می‌سازید.
- لاگ‌های سنگین را با `grep` فیلتر کرده و فایل‌ها را با یک دستور مدیریت می‌کنید.
- اسکریپت‌های اتوماسیون اختصاصی خود را برای حذف کارهای تکراری می‌نویسید.

## 🧪 زمین تمرین

تمام تمرین‌ها در یک پوشه امن انجام می‌شن — خرابکاریش مجانیه:

```bash
mkdir ~/cli-playground && cd ~/cli-playground
```

(اگه این دو خط رو الان نفهمیدی — دقیقاً همون جاییه که فصل ۳ شروع می‌شه 😄)

**قانون طلایی دوره:** ترمینال با Enter کارت رو *اجرا* می‌کنه، نه با تایپ. تا Enter نزدی هیچی اتفاق نمی‌افته — پس با خیال راحت تایپ کن. و هر چیزی که نمی‌فهمی، Tab بزن (فصل ۳) و --help بگیر (فصل ۵) — این دو تا، حافظه‌ت رو لازم ندارن.
